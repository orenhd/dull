# אייקונים (`src/assets/icons/`)

נוסף 2026-09-23 (docs/PRD.md סעיף 60, בקשת Oren) - תשתית לאייקוני SVG
סקיילבילית, לקראת שימוש חוזר עתידי (היום יש אייקון אחד, `basket.svg` -
זה בדיוק הזמן הנכון להקים את המוסכמה, לפני שיצטבר עוד אייקון "מוזרק"
ידנית ישירות בתוך TSX).

## המוסכמה

כל אייקון - קובץ `.svg` עצמאי בתיקייה הזו (לא מוזרק כ-JSX בתוך `.tsx`).
מיובא כרכיב React דרך [`vite-plugin-svgr`](https://github.com/pd4d10/vite-plugin-svgr)
(מוגדר ב-`vite.config.ts`), עם סיומת שאילתת `?react`:

```tsx
import Basket from "@/assets/icons/basket.svg?react";

<Basket className="size-6" />
```

זה המקביל המודרני (Vite) למה שהיה נהוג ב-webpack (למשל דרך
`@svgr/webpack`, `import { ReactComponent as Basket } from "./basket.svg"`)
- אותו רעיון בדיוק (SVGR), רק תחביר-ייבוא שונה מעט: ב-Vite זה
default-export + `?react`, לא named `ReactComponent`. **לא מנגנון מיושן** -
`vite-plugin-svgr` מתוחזק באופן פעיל (גרסה 5.2.0 נכון לכתיבת שורות אלו).

## עקרונות לאייקון חדש

- `viewBox="0 0 24 24"` (עקבי בין אייקונים - קל לערבב בגדלים שונים
  דרך `className="size-*"` בלי לדאוג ליחס-רוחב-גובה שונה בין אייקונים).
- `stroke="currentColor"` (לא `fill`, אלא אם האייקון אכן "מלא" מעצם
  טיבו) - כדי שיירש צבע אוטומטית דרך `text-*`/`color` רגיל של Tailwind,
  בלי `prop` צבע נפרד. SVGR מעביר props (כולל `className`) אוטומטית
  אל ה-`<svg>` השורשי.
- `aria-hidden="true"` כברירת מחדל על ה-`<svg>` עצמו - אייקונים כאן הם
  עיטוריים-בעיקרם (הטקסט הנגיש האמיתי חי ב-`sr-only` span ליד, לא
  באייקון) - ראו `SiteHeader.tsx`/`CartLink` לדוגמה מלאה.
- הערות-תיעוד (החלטות עיצוב, "למה" הצורה כזו) - בתוך קובץ ה-`.svg` עצמו
  כהערת XML (`<!-- ... -->`), לא בקובץ `.tsx` שמייבא אותו (שם רק
  שימוש/עיצוב-שכבת-שימוש, לא תיעוד גיאומטריית-הצורה).

## הערה על `VariantSelector.tsx`

ה-chevron שם משתמש בטכניקה שונה (`mask-image` על `<span>`, לא רכיב-SVG
נפרד) - נשאר כך בינתיים, לא הוגר לכאן אוטומטית (לא התבקש, ותבנית ה-mask
משרתת שם מטרה אחרת - צביעת רקע דרך Tailwind, לא stroke/fill רגיל). אם
יעלה צורך עתידי לאחד את שתי הטכניקות - שיחה נפרדת.
